A-SHARE LEVEL-2 MARKET DATA API

A 股 Level-2 实时行情数据接口

达塔接口是一套面向程序自动化的 A 股 Level-2 实时行情数据接口。程序连接本机数据服务后，可用统一的 HTTP 与 WebSocket 方式获取 level2 逐笔成交、逐笔委托、十档盘口、委托队列、集合竞价千档快照、K 线与资金流向等数据，适用于量化研究、因子回测、盯盘工具与 AI Agent 自动取数。

接口能力总览

达塔接口是底层能力层，不是某一套固定界面。下列通道均为程序调用接口，同一套底层可生长出工作台、图表看板、实时大屏与自动化工具。

通道类型主要能力
D101行情字段 / 增量推送203 个正式行情字段，单条 snapshot 最多请求 255 个字段
D201WebSocket 实时行情盘口、逐笔委托、逐笔成交
D202WebSocket 实时行情实时深度、逐笔委托、逐笔成交、竞价快照
D1HTTP 查询资讯、行情摘要、历史排行、板块与资金数据
D2HTTP 查询数据中心、市场统计、事件数据、资金流向
D3历史复盘按「交易日期 + 股票代码」读取历史复盘数据
D4品种与历史证券品种池、历史数据
D6市场数据行情、K 线、资金流向、涨跌排行、板块、公告研报、融资融券

支持的平台

  • Windows（AMD64 桌面客户端）
  • macOS（Apple Silicon ARM64 与 Intel x86_64）
  • Linux 桌面（AMD64）
  • Linux 无界面服务器（headless，供 AI Agent 与自动化程序调用）

全部安装包与文档见 下载中心，并提供 SHA-256 校验值。

接入方式

客户端启动并登录后，在本机开启数据服务，程序连接本机地址即可调用接口，无需了解外部线路与认证细节。

  • HTTP 接口：默认本机地址 localhost:8080，适合历史数据查询与低频获取。
  • WebSocket 接口：实时推送，适合盘口、逐笔委托、逐笔成交等高频数据。
  • 无界面服务器：程序自动登录、启动、取数，适合服务器部署与 AI Agent。

代码示例见 downloads/examples/，其中 ai_control.py 仅用 Python 标准库即完成登录与取数。

常见问题

达塔接口是什么？
一套面向程序自动化的 A 股行情数据接口，提供 Level-1 与 Level-2 实时行情；连接本机数据服务后即可用统一的 HTTP 与 WebSocket 方式获取数据。
支持哪些 Level-2 数据？
逐笔成交、逐笔委托、十档盘口、委托队列、集合竞价千档快照等。D101 通道提供 203 个正式行情字段。
支持哪些操作系统？
Windows AMD64、macOS（ARM64 与 Intel）、Linux 桌面与 Linux 无界面服务器，共 5 个平台。
怎么接入？需要写代码吗？
可用图形工作台手动查看，也可用 Python 或任意语言通过 HTTP / WebSocket 接口自动调用。
AI Agent 或自动化程序能用吗？
可以。提供 Linux 无界面服务器版本，程序可自动登录、启动服务并取数，无需人工操作界面。
数据是实时推送的吗？
是。D101 为增量行情（字段变化才推送），D201 / D202 通过 WebSocket 实时推送盘口与逐笔数据。
