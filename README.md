# 达塔接口 datas

> **达塔接口是一个面向 A股市场的实时行情数据客户端**，提供 A股实时行情接口、
> Level2 逐笔数据与十档盘口行情数据。它把逐笔成交、涨停板、龙虎榜、资金流向、
> 板块异动等数据，通过统一的行情数据接口提供给用户自己的程序，用于量化研究、
> 盯盘工具、策略回测和 AI Agent 取数。

支持 Windows、macOS（Apple Silicon / Intel）、Linux，包括不需要桌面环境的
无界面服务器版本。

## 能拿到哪些数据

覆盖 A股股票数据的主要类别：

| 类别 | 内容 |
|---|---|
| **Level-2 逐笔** | 逐笔成交、逐笔委托、买卖盘口档位 |
| **盘口快照** | 十档行情、集合竞价快照、盘口资金 |
| **实时行情** | 个股实时价、指数实时行情、跨市场行情 |
| **K线** | 日线、分钟线、指数 K线 |
| **涨停与异动** | 涨停板、涨跌停统计、涨跌排行、板块异动、个股异动 |
| **资金与筹码** | 资金流向、盘口资金、筹码分析、市场情绪 |
| **资金面** | 融资融券、沪深港通（北向资金）、大宗交易 |
| **题材与榜单** | 龙虎榜、板块行情、热门主题与关联证券 |
| **公司数据** | 财务与业绩、研报公告、个股诊断、F10 资料 |
| **基础工具** | 交易日历、证券搜索 |

完整字段和调用方式见 [`docs/`](docs/)。

## 和其他方案比，它解决什么问题

A股 Level-2 行情数据（逐笔成交、逐笔委托、十档盘口）的常见获取方式：

| 方式 | 门槛 |
|---|---|
| 免费开源库（akshare、mootdx 等） | 通常只有 Level-1 行情，拿不到 Level-2 逐笔与十档 |
| 券商 QMT / PTrade | 需**开通证券账户**并满足资产门槛，通常是几十万级别 |
| 行情 API 服务商 | 多为纯接口，按月或按标的计费 |
| **达塔接口** | **不用开户、不用满足资产门槛**，装客户端即可用 |

**不需要开证券账户、不需要满足资产要求**，是它和券商免费通道最主要的区别；
对只想拿数据、不想为数据去开户的人来说，这是更短的一条路。

也需要说清楚边界：它是**行情数据客户端**，只提供数据，**不含交易下单功能**。
如果你要的是实盘交易接口，券商通道更合适。

## 怎么拿到

```text
① 到官网下载对应平台的客户端
② 注册 / 登录（新手机号自动注册）
③ 在客户端完成授权激活

```

安装包（Windows zip / macOS dmg / Linux tar.gz）在官网与 GitHub Pages 镜像站提供。

### 授权与版本

客户端需授权后使用。不同版本覆盖的数据范围不同，**当前版本与报价以官网说明
为准：<https://datas.lovestoblog.com/>**

本仓库不涉及授权的发放，也不受理购买。

> **只运行客户端无法创建账号。** 账号注册、登录和授权校验都需要能访问授权
> 服务。纯内网、离线或无法访问外网的环境下，客户端登录注册不了，也无法激活。
> 部署前请先确认所在网络能正常访问外网。

### 无界面服务器 / AI Agent

服务器、云主机、没有浏览器的环境不需要点界面。客户端提供本机接口，程序按
固定流程调用即可：

```bash
export DI_PHONE='你的手机号'
export DI_PASSWORD='你的密码'

python examples/ai_control.py status
python examples/ai_control.py login
```

需要激活时注入卡密，然后启动：

```bash
export DI_CARD_KEY='你的卡密'
python examples/ai_control.py recharge
python examples/ai_control.py start
python examples/ai_control.py smoke
```

用完清理：

```bash
unset DI_PHONE DI_PASSWORD DI_CARD_KEY
```

完整流程见 [`docs/无界面服务器与AI自动化操作.md`](docs/无界面服务器与AI自动化操作.md)。

## 常见问题

**Q：必须装客户端才能用吗？**

是的。接口都在本机运行的客户端里，需要先安装客户端、登录并完成授权，才能取数。
下载地址见 <https://datas.lovestoblog.com/>（镜像站
<https://zzhahn.github.io/a_stock_level2_data/>）。

**Q：授权在哪里获取？**

授权由官网提供，本仓库不提供、也不受理。打开
<https://datas.lovestoblog.com/> 获取；新用户可先在官网了解试用方式。

**Q：各版本有什么区别、怎么收费？**

版本覆盖的数据范围与当前报价，以官网说明为准：
<https://datas.lovestoblog.com/>。价格会调整，本仓库不记录具体金额。

**Q：内网 / 离线机器能登录吗？**

不能。账号注册、登录和授权都需要访问授权服务，请先确认网络能正常访问外网。

**Q：取行情数据需要自己找数据源吗？**

不需要。客户端封装好了数据获取，你只需要写程序调用接口。

**Q：服务器上没有浏览器能用吗？**

能。无界面环境全程走本机接口，见
[无界面服务器与AI自动化操作](docs/无界面服务器与AI自动化操作.md)。

**Q：一台机器只能跑一个客户端吗？**

macOS 有单实例保护；Windows 和 Linux 按进程管理即可。

**Q：程序返回 403 是什么原因？**

一般是目标数据权限未开通或会话已过期。检查状态里的产品权限和到期时间，不需要
反复重装。

**Q：客户端能不能装在另一台机器上，程序在这台机器跑？**

可以，但**不要把服务端口直接开到公网**。正确做法是用 SSH 隧道把端口转发到
本机，具体见无界面文档。

**Q：支持哪些编程语言？**

接口是标准 HTTP 和 WebSocket，任何能发请求的语言都可以。仓库里的示例是
Python（标准库），方便直接跑通。

**Q：需要开证券账户吗？**

不需要。它不依赖券商通道，装客户端、登录授权后即可取数。

**Q：和券商 QMT / PTrade 免费给的 Level-2 比，区别在哪？**

券商通道需要先开通证券账户并满足资产门槛；它不需要开户，也没有资产要求。

**Q：免费开源库（akshare、mootdx 等）能替代吗？**

通常不能。这类库主要覆盖 Level-1 行情、日线、财务等公开数据，**一般拿不到
Level-2 的逐笔成交、逐笔委托和十档盘口**。如果你的策略需要盘口级数据，
需要用能提供 Level-2 的通道。

**Q：它能帮我下单交易吗？**

不能。它是**行情数据客户端**，只提供数据，不含交易下单功能。
